# Event Details Page

## Purpose

Present complete public/authorized event information and the registration entry point.

## Display

Event title, description, date/time, venue, rooms/location, registration status/window, featured information, and relevant sessions/speakers.

## Actions

Register, open Schedule, open Speaker Directory, and open Venue/location information where enabled.

## Rules

Only published/authorized event information is shown to attendees. Registration action must verify current eligibility/status before creating a registration.

## States

Loading, not found, registration closed, registration unavailable, normal, and error/retry.
