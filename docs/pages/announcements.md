# Announcements Page

## Purpose

Display published announcements scoped to the current user's organization/event access.

## Attendee View

Show title, message, publish time, optional event context, and approved attachments/links.

## Admin View

Authorized users can create drafts, edit drafts, schedule/publish where supported, and archive announcements.

## Visibility Rules

Draft and restricted announcements must not be returned to unauthorized users. Event-specific announcements must be scoped to that event.

## States

Loading, no announcements, normal, network error/retry, and permission denied.
