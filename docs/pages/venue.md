# Venue Page

## Purpose

Display venue details and associated rooms for authorized event-management users and attendee-facing location context where appropriate.

## Data

Venue name, address/location, contact information permitted by policy, map/location metadata, rooms, capacity, and status.

## Admin Actions

Create, edit, archive, and manage rooms when the user's permissions allow.

## Attendee View

Expose only event-relevant location information needed to navigate the event.

## Rules

Venue and room records must remain scoped to their owning organization/event relationships. Archived venues should not appear in active event queries.
