# Speaker Directory

## Purpose

Browse approved speakers associated with the selected published event.

## Data

Speaker name, photo, title/organization, short biography, and approved session count/links.

## Query

Load speakers through authorized event/session relationships. Avoid exposing unrelated or unpublished speakers.

## Interactions

Search/filter where enabled; select a speaker to open Speaker Profile.

## States

Loading, empty directory, search no-results, permission/error, and normal list.
