# Administration Pages

## Dashboard

Show organization/event KPIs, active events, registration/check-in summaries, announcements, and operational shortcuts based on permissions.

## Management Pages

Organizations, Users, Events, Venues, Rooms, Tracks, Sessions, Speakers, Registrations, Volunteers, Announcements, Sponsors/Vendors, Check-In, and Reports.

## Access

Each page requires the appropriate role/permission. Backend rules independently enforce access.

## Common States

Loading, empty, validation error, permission denied, network error/retry, success confirmation.

## Data Safety

Avoid permanent deletion of records needed for historical reporting. Prefer archive/status transitions.
