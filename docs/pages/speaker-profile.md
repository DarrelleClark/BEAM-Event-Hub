# Speaker Profile Page

## Purpose

Display an approved speaker profile and their published session relationships.

## Display

Photo, name, title/organization, biography, approved links, and associated published sessions.

## Navigation

Session selection opens Session Details. Back returns to Speaker Directory or the originating page.

## Security

Only approved public profile fields are displayed to attendees. Internal contact information, permissions, and administrative metadata remain restricted.

## States

Loading, not found, no published sessions, error/retry, and normal.
