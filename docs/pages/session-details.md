# Session Details Page

## Purpose

Present complete information about an event session.

## Data

Session title, description, start/end time, room, venue, track, event, assigned speakers, and approved materials/links.

## Actions

Add to personal schedule where enabled; remove from schedule; open speaker profiles; return to schedule.

## Rules

Only sessions belonging to the selected/authorized event should load. Draft/private sessions must not appear to attendees.

## States

Loading, session not found, unavailable/unauthorized, normal, and network error/retry.
