# Speaker Queries

## Event Speakers

Resolve speakers through published sessions/speaker assignments for the selected event.

## Speaker Directory

Return only approved public profile fields for speakers associated with the authorized event.

## Speaker Detail

Load a speaker by ID after confirming the requesting user can access the profile.

## Assigned Sessions

For speaker dashboards, resolve assignments by authenticated speaker/user relationship and show only authorized sessions.

## Security

Do not expose internal speaker contact data, permissions, or unpublished assignments through attendee queries.
