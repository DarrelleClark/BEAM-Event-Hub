# Bottom Navigation

Primary attendee navigation component.

**Destinations:** Home, Schedule, Speakers, QR Pass/Profile or other approved core destinations.

**Inputs:** currentIndex/currentRoute, role, notification state.

**Behavior:** selected state follows current page; inaccessible destinations are hidden or disabled; navigation does not bypass authentication.
